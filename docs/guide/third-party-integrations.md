# Third-party Integrations

This comprehensive guide covers integrating Yatra with various third-party plugins and services to extend functionality.

## Integration Overview

Yatra supports integration with numerous third-party plugins and services to enhance your travel booking website.

### Available Integrations

- **Page Builders**: Elementor, Divi, Beaver Builder
- **Membership Plugins**: MemberPress, Restrict Content Pro
- **Analytics Tools**: Google Analytics, MonsterInsights
- **SEO Plugins**: Yoast SEO, Rank Math
- **Translation Plugins**: WPML, Polylang
- **Form Plugins**: Contact Form 7, Gravity Forms
- **Email Marketing**: Mailchimp, Constant Contact

## Page Builder Integrations

### Divi Builder Integration

#### Setup Process

1. **Install Divi Builder**:
   - Navigate to **Plugins → Add New**
   - Search for "Divi Builder"
   - Install and activate

2. **Enable Integration**:
   - Navigate to **Yatra → Settings → Integration**
   - Enable Divi Builder integration
   - Save settings

#### Divi Modules

Yatra provides custom Divi modules:

- **Tour List**: Display tour listings
- **Tour Details**: Show tour information
- **Booking Form**: Custom booking form
- **Hotel List**: Display hotel listings
- **Room Booking**: Room booking form

#### Usage

1. **Edit Page** with Divi Builder
2. **Add Module** from Yatra category
3. **Configure** module settings
4. **Save** and publish

## Analytics Integration

### Google Analytics Integration

#### Setup Process

1. **Install Google Analytics Plugin**:
   - Install MonsterInsights or similar
   - Configure Google Analytics

2. **Enable Integration**:
   - Navigate to **Yatra → Settings → Analytics**
   - Enable Google Analytics tracking
   - Configure tracking settings

#### Tracking Features

- **Booking Events**: Track booking conversions
- **Page Views**: Track tour and hotel page views
- **User Behavior**: Track user interactions
- **Revenue Tracking**: Track booking revenue

#### Event Tracking

Yatra automatically tracks these events:

- **tour_view**: When a tour is viewed
- **hotel_view**: When a hotel is viewed
- **booking_start**: When booking process starts
- **booking_complete**: When booking is completed
- **payment_success**: When payment is successful

### MonsterInsights Integration
