## Free vs Pro at a glance

| Capability                                       | Free | <span class="doc-pro-pill">Pro</span> |
|---                                                | ---  | --- |
| Trips, itineraries, FAQs, attributes              | ✅   | ✅  |
| Destinations, activities, trip categories         | ✅   | ✅  |
| Departures, capacity, recurring availability      | ✅   | ✅  |
| Coupons &amp; basic discounts                     | ✅   | ✅  |
| Booking lifecycle, traveler accounts              | ✅   | ✅  |
| Reviews &amp; reporting                           | ✅   | ✅  |
| **PayPal** &amp; **Pay Later** gateways           | ✅   | ✅  |
| Stripe, Razorpay, Mollie, Paystack, Square, Authorize.Net, Bank Transfer | — | ✅ |
| Deposits / partial payments (Flexible Payments)   | —    | ✅  |
| Dynamic Pricing rules engine                      | —    | ✅  |
| Email Automation (sequences, logs)                | —    | ✅  |
| Google Calendar sync                              | —    | ✅  |
| Additional Services (upsells)                     | —    | ✅  |
| Trip Consent (waivers &amp; signatures)           | —    | ✅  |
| Custom Booking Questions                          | —    | ✅  |
| Mailchimp · Facebook Pixel · GA4 Enhanced         | —    | ✅  |
| Abandoned Booking Recovery                        | —    | ✅  |
| Saved trips / wishlist (when enabled)             | —    | ✅  |
| Custom Landing Pages for taxonomies               | —    | ✅  |

> Modules need a paid plan. Purchase on [wpyatra.com/pricing](https://wpyatra.com/pricing/) — WordPress adds **Upgrade to Pro** under the Yatra menu when you’re still on free.
