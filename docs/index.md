## Welcome to Yatra Documentation

Yatra is a powerful WordPress travel booking plugin that helps you create and manage tours, hotels, and activities with ease. Whether you're running a small tour company or a large travel agency, Yatra provides all the tools you need to accept online bookings and grow your business.

## Quick Start

1. **Install Yatra** from the WordPress repository or by uploading the plugin files
2. **Configure basic settings** in the Yatra admin panel
3. **Create your first tour or hotel** with pricing and availability
4. **Set up payment methods** to start accepting bookings
5. **Customize the appearance** to match your brand

## Key Features

### 🎯 **Tour Management**
- Create unlimited tours with detailed descriptions
- Set flexible pricing options (per person, per group, etc.)
- Manage availability with advanced scheduling
- Add tour highlights, itineraries, and galleries

### 🏨 **Hotel Booking**
- Complete hotel and room management system
- Room availability calendar with real-time updates
- Flexible pricing based on season, occupancy, or custom rules
- Online booking with instant confirmation

### 💰 **Payment Processing**
- Multiple payment gateway support
- Secure online transactions
- Partial payment and deposit options
- Automatic invoice generation

### 🎨 **Design & UX**
- Modern, responsive booking forms
- Customizable email notifications
- Integration with popular WordPress themes
- Mobile-first design approach

### 🔧 **Advanced Features**
- Coupon and discount system
- Multi-language support
- Tax calculation and management
- Export and reporting tools
